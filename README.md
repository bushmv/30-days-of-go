# 30-days-of-go

task

Репозиторий содержит 30 небольших проектов на языке Go для практики программирования. Лучше всего каждый день брать один проект, прочитать `README.md` этого дня, посмотреть реализацию в `.go` файлах и постараться повторить проект самостоятельно.

## Список тем

01. Circular Buffer
02. Tower of Hanoi
03. Console based task management app
04. Decorator pattern
